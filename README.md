DESCRIPCIÓN DEL TEMPLATE Y RAZONES Para la migración del sitio web de ECOPILGUA se seleccionó la plantilla “Nordic” de ThemeWagon (https://themewagon.com/themes/nordic/), que consiste en una plantilla gratuita y moderna, con una estructura similar a la pensada por el equipo para la mejora del sitio original.  La elección de este template se basó principalmente en su forma adaptable para el rubro de ECOPILGUA, que requiere de una alta personalización e imágenes para la venta de productos, con el fin de que el usuario pueda acceder a ellos fácilmente para su visualización.  Este template presenta un diseño limpio que permite destacar de mejor manera los productos y mantener la identidad visual que fue trabajada en las evaluaciones anteriores, basada en colores naturales y una estética sustentable, alineada con la imagen de la marca. Además, se escogió por ser una opción de uso gratuito y de fácil edición. Ello facilitó la migración de contenidos y la personalización de secciones según las necesidades identificadas del proyecto. Otro factor importante fue la posibilidad de incorporar fotografías de alta calidad que fueron optimizadas por el equipo de trabajo, permitiendo mejorar la presentación de los productos y generar un mayor impacto visual en los usuarios.  Finalmente, el template posee un diseño responsivo que asegura una correcta visualización y navegación en distintos dispositivos, manteniendo la funcionalidad y experiencia de usuario. DESCRIPCIÓN DE PROBLEMAS Y RESOLUCIÓN  El principal problema detectado durante el proceso de migración del sitio web de ECOPILGUA fue la baja calidad de las imágenes facilitadas para el desarrollo del proyecto. Estas no solo tenían baja resolución, poca nitidez y diferencias de tamaño, sino que no cumplían con criterios básicos de fotografía, lo que afectaba la estética general y la presentación visual de los productos dentro del nuevo template seleccionado. Para resolver este problema, se tomó la decisión grupal de optimizar las imágenes mediante herramientas de inteligencia artificial, mejorando su resolución, nitidez y calidad visual sin perder la esencia de los productos originales. Este proceso permitió obtener imágenes más adecuadas para una presentación más profesional dentro del sitio web. A continuación de dejan algunos ejemplos de las imágenes optimizadas.
