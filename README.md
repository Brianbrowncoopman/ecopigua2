# Eco Pilgua - Evolución del Proyecto Web 🌿

Este repositorio documenta la evolución técnica del sitio web de **Eco Pilgua**, un emprendimiento de papelería creativa y sublimación personalizada. El proyecto recorre desde una estructura básica hasta una implementación profesional moderna.

## 🚀 Evolución Técnica

El proyecto se desarrolló en tres etapas clave:

1.  **Etapa 1: Esqueleto Estructural (HTML Puro)**
    * Creación de la base semántica del sitio utilizando etiquetas `header`, `main` y `section`.
    * Definición de secciones principales: Inicio, Misión, Visión, Productos y Contacto.

2.  **Etapa 2: Diseño Personalizado (HTML + CSS)**
    * Implementación de un archivo `style.css` robusto con diseño responsivo.
    * Uso de **Flexbox** y **CSS Grid** para organizar la galería de productos y testimonios.
    * Configuración de fondos múltiples con degradados y logotipos como marca de agua.
    * Integración de **Font Awesome** para mejorar la visualización de redes sociales.

3.  **Etapa 3: Modernización con Tailwind CSS**
    * Refactorización completa utilizando un template profesional de **ThemeWagon**.
    * Implementación de **Tailwind CSS** para un diseño moderno, optimizado y móvil-primero.
    * Uso de clases utilitarias para efectos de hover y transiciones suaves.

## 🛠️ Tecnologías y Herramientas

* **Lenguajes:** HTML5, CSS3, JavaScript.
* **Framework de Estilos:** Tailwind CSS.
* **Control de Versiones:** GitHub (para el historial de cambios y colaboración).
* **Despliegue (Hosting):** Vercel (integración continua desde el repositorio).

## 📂 Estructura del Proyecto

* `index.html`: Versión final optimizada con Tailwind CSS.
* `index2.html`: Versión intermedia con CSS personalizado.
* `style.css`: Hoja de estilos detallada para la versión personalizada.
* `/src`: Recursos gráficos, incluyendo el logotipo y fotos de productos.
